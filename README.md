# Pinterest Clone - LookIn Web

This project is a Pinterest clone developed for educational purposes. It allows users to create an account, post images with titles and descriptions, comment on and reply to other users' comments, view their own and others' posts, as well as edit their personal information (username and email) and manage their posts by editing or deleting them.

# Technologies Used
- TypeScript
- React
- Node.js
- Express
- Prisma ORM
- PostgreSQL (Neon)
- CSS Modules

# Features
- User registration and login
- JWT authentication
- Image posting (posts)
- Post editing and deletion
- Comments and replies
- User profile
- Account information editing
